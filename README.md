# Raj Panwar — Portfolio

A responsive React + Vite developer portfolio with an interactive command-terminal easter egg.

## Run locally
```bash
npm install
npm run dev
```

## Before publishing
1. Replace `YOUR_EMAIL@example.com` and `rajpanwar@example.com` with your real email.
2. Add your actual LinkedIn profile URL.
3. Verify every project description and achievement. Remove anything that is not accurate.
4. Add a real resume link if desired.
5. Run `npm run build`.

## Deploy with AWS Amplify Hosting
1. Push this repository to GitHub.
2. Open AWS Amplify in the AWS Console and choose **New app → Host web app**.
3. Connect GitHub and select this repository and branch.
4. Build settings:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Save and deploy. Keep the generated public URL available through judging.

No backend or environment variables are required.
